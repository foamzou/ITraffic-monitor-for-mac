## Added

- **Update check.** Click the version number in the header. If a newer release
  exists it turns into `v0.x.y ↑`; click again to open the release page.

  It only ever runs when you click it — no timer, no check at launch, and no
  "check automatically" setting. iTraffic lists the network activity of every
  process including its own, so a background poll would show up in your own
  process list as unexplained traffic from the one tool whose job is to explain
  traffic. Nothing about your machine is sent; the request is a plain GET to the
  public GitHub releases API.

## Install

Download `ITraffic-v0.2.2.zip`, unzip, drop `ITraffic.app` into `/Applications`.

Or with Homebrew:

```bash
brew update && brew upgrade itraffic
```

## Compatibility

- macOS 10.15 (Catalina) or later
- Apple Silicon and Intel (universal binary)
