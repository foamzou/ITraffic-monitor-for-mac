## Fixed

- **The process list showed double the real rate** ([#28](https://github.com/foamzou/ITraffic-monitor-for-mac/issues/28)). `nettop` samples every 2 seconds in delta mode. The menu bar divided each sample by that interval and printed a per-second rate; the popover list rendered the raw 2-second delta, so every row read 2× the menu bar. Both now report bytes per second, and the field name carries the unit (`inBytesPerSec`) so the two surfaces can't silently drift apart again. Thanks [@lbxxgn](https://github.com/lbxxgn) for a report precise enough to fix from.

## Changed

- **Signed with a Developer ID and notarised by Apple.** Earlier builds were ad-hoc signed, so the first launch needed right-click → Open — and on recent macOS, a detour through System Settings → Privacy & Security. This one opens on a double-click.
- A `Bytetally` link now sits next to `Github` in the header. Bytetally is the full edition from the same developer: usage history, charts, and per-app limits. Same grey link style as the other header items — no popup, no badge, nothing added to the process list.

## Install

Download `ITraffic-v0.2.1.zip`, unzip, drop `ITraffic.app` into `/Applications`.

Or with Homebrew:

```bash
brew update && brew upgrade itraffic
```

## Compatibility

- macOS 10.15 (Catalina) or later
- Apple Silicon and Intel (universal binary)
